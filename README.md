## スケジュールテンプレート

毎年の大まかなスケジュール感です。

### 第1フェーズ：ノミネート語リストの作成まで

（0.5週）

1. 初回ノミネート開始（シン・選考委員→事務局）

1人最大10語まで。順位は不要です。
「推薦の辞」があれば添えてもOKです。

ノミネート用フォームは別途案内します。

2. 第1回締め切り

3. ノミネート語リスト仮共有（事務局→シン・選考委員）

リストのURLは別途案内します

（0.5～1週）

4. ノミネート語リストの完成
   * 4-1．　疑義照会（事務局→シン・選考委員）
   * ノミネート語の新語要件に疑義のある場合、ノミネート元の選考委員に照会します
   * 疑義照会を受けた選考委員は、既存の語釈にない新しさを説明します
   * 「用例数の増加」「用法の拡大」などがあっても、新しい意味を認めがたいと判断したものについては事務局裁量によりノミネート語から除外します
   * 4-2. 追加ノミネート（シン・選考委員会メンバー→事務局）
   * 仮共有したリストに未掲載の候補のノミネートを受け付けます。トップ10部門は最大3語、選外部門1語とします
   * 初回ノミネートで重複した語数が3語を上回った選考委員については、その重複数まで追加ノミネート可とします

5. ノミネート語リスト共有（事務局→シン・選考委員会メンバー）

### 第2フェーズ：投票から結果発表まで

（1週）

1. 第1回投票（シン・今年の新語選考委員会）

1位から10位までの10語を投票します。選外も同様に2語を投票します
事前登録制により、選考委員以外からの投票も受け付けます
投票用フォームは別途案内します

候補語リストからの絞り込みが目的です
第2回への通過条件は「スコアが10位の80%以上である語」とします

2. 投票締め切り

（0.5週）

3. 第2回投票（シン・選考委員）

絞り込んだ候補語を対象に、順位確定のための投票を行います

4. 投票結果集計・共有（事務局）

（0.5週）

5. 講評作成（事務局）

6. 講評共有（事務局→シン・選考委員）

記事URLと参照用パスワードを案内します

（0.5週）

7. フィードバック期間（シン・選考委員→事務局）

公開前に供覧し、内容その他に不備があれば修正します

8. 発表（事務局）

講評とともに、三省堂「今年の新語」選考発表会の前に公開します
期日は発表会日程に合わせて調整します
